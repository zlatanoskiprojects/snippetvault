A workspace is the shared space where your snippets live. Any signed-in user can create a workspace, and the creator becomes its owner.

## Create a workspace

Minimum role: none. Any signed-in user can do this.

1. Sign in and open the dashboard.
2. Open the workspace menu at the top of the sidebar.
3. Choose to add a workspace.
4. Enter a **Workspace name** and select **Create workspace**.

The new workspace is private. You are its only member and its owner, and you can add members later. See [Invitations](/invitations).

If you have no workspace yet, the dashboard asks you to create one first.

## Save your first snippet

Minimum role: editor.

1. Select **New snippet**.
2. Enter a **Title**, a **Language** and the code. A **Description** is optional.
3. Choose a **Visibility** and, optionally, add tags and pick a **Project**.
4. Save the snippet.

The snippet is stored in the workspace you currently have selected. See [Snippets](/snippets) for every field.

## Switch between workspaces

Minimum role: viewer.

Open the workspace menu and pick another workspace. The menu lists every workspace you belong to, including ones you joined through an [invitation](/invitations).
