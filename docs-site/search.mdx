---
title: "Search"
description: "Find snippets in a workspace by text, language and tag."
---

Search looks through the snippets of the workspace you have selected.

## Search snippets

Minimum role: viewer.

1. Select the **Search snippets** box in the sidebar, or the **Search** button in the top bar.
2. Type your terms in the search field.

A snippet matches when your text appears, ignoring case, in its title, description, code or any of its tags. Results update as you type.


## Narrow the results

Minimum role: viewer.

1. Under **Language**, select one language to show only snippets in it. Select it again to clear it.
2. Under **Tags**, select one or more tags. A snippet must carry every selected tag.
3. Under **Sort by**, choose **Date modified** (default), **Date created** or **Title A–Z**.

## Leave search

Minimum role: viewer.

1. Press Escape, or select **Close search**.

This clears the search text and returns to the snippet list.

<Note>
Search never covers other workspaces. Switch workspace first to search elsewhere.
</Note>
