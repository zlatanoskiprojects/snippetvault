---
title: "Search"
description: "Find snippets in a workspace by text, language and tag."
---

Search looks through the snippets of the workspace you have selected. Every member, including viewers, can use it.

## Search snippets

1. Select the search box in the sidebar, or the search button in the top bar.
2. Type your terms.

A snippet matches when your text appears, ignoring case, in its title, description, code or any of its tags. Results update as you type.

## Narrow the results

The search view has three sets of controls:

- **Language**: select one language to show only snippets in it. Select it again to clear it.
- **Tags**: select one or more tags. A snippet must carry every selected tag.
- **Sort by**: **Date modified** (default), **Date created** or **Title A–Z**.

## Leave search

Press Escape or select the close button. This clears the search text and returns to the snippet list.

<Note>
Search never covers other workspaces. Switch workspace first to search elsewhere.
</Note>
