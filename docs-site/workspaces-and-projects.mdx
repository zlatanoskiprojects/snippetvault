---
title: "Workspaces and projects"
description: "How workspaces and projects organize your snippets."
---

A workspace is the shared space that holds snippets and members, and a project is an optional group of snippets inside it. Which actions you can take depends on your role in the workspace.

## Switch or add a workspace

Any member can switch to another workspace they belong to, and any signed-in user can create a workspace and becomes its owner.

1. Open the workspace menu at the top of the sidebar.
2. Pick a workspace from the **Workspaces** list, or choose **Add workspace**.
3. To add one, enter a **Workspace name** and select **Create workspace**.

See [Your first workspace](/first-workspace).

## Rename or delete a workspace

Only the owner can rename or delete a workspace. Deleting a workspace permanently removes its members, invitations, projects, snippets, comments and versions. User accounts are kept.

## Create a project

Owners and editors can create projects.

1. Open **Projects** in the sidebar.
2. Select **New project**.
3. Enter a **Name** (required, up to 255 characters) and an optional **Description** (up to 1,000 characters).
4. Select **Create project**.

Viewers can see the project list but cannot create projects.

## Edit or delete a project

Only the owner can edit or delete a project.

1. Open **Projects** and find the project card.
2. Use the edit control to change the name or description and select **Save changes**, or use the delete control to remove the project.

Deleting a project does not delete its snippets. They stay in the workspace without a project.

## Put a snippet in a project

Owners and editors choose a **Project** when they create or edit a snippet, or pick **No project** to take it out of one. A snippet and its project must belong to the same workspace. See [Snippets](/snippets).

## Browse a project

Select a project card to list only the snippets assigned to it. Each card shows the description and the number of snippets. All members, including viewers, can browse projects.

<Note>
Editors can create projects but cannot rename or delete them afterwards; only the owner can.
</Note>
