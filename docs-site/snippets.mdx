A snippet is a saved piece of code with a title and a language, kept in a workspace. Owners and editors can create, edit and delete snippets; viewers can read and copy them.

## Create a snippet

Owners and editors only.

1. Select **New snippet**.
2. Enter a **Title** (required, up to 200 characters).
3. Optionally add a **Description** (up to 5,000 characters).
4. Choose a **Language** and write the code in the editor. Code is required and limited to 65,000 characters.
5. Optionally set **Visibility**, add **Tags**, and choose a **Project**.
6. Select **Save snippet**.

## Supported languages

JavaScript, TypeScript, Python, Java, C++, Go, Rust and SQL. Other languages are rejected.

## Edit a snippet

Owners and editors only. Open a snippet, select **Edit**, change the fields and select **Save changes**. You can add an optional **Change note** (up to 500 characters). If the code changes, the previous code may be saved as a version; see [Version history](/version-history).

Owners and editors can also move a snippet to another project or take it out of its project. See [Workspaces and projects](/workspaces-and-projects).

## Delete a snippet

Owners and editors only. Open the snippet, select **Delete** and confirm. Deleting a snippet also removes its versions and comments.

## Copy code

Any member, including viewers, can open a snippet and select **Copy**.

## Visibility

A snippet is **Private** by default. Setting it to **Public** creates a share link that anyone can open without signing in. Only owners and editors can change visibility. See [Public sharing](/public-sharing).

## Related

- [Tags](/tags) label snippets.
- [Search](/search) finds snippets by title, language, description, tag or code.
- [Comments](/comments) let members discuss a snippet.
