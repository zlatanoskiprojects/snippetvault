---
title: "Tags"
description: "Label snippets with tags to find them later."
---

A tag is a short label attached to a snippet. Owners and editors can add and remove tags; viewers can see tags and filter by them.

## Add tags to a snippet

Minimum role: editor.

1. Open the snippet form by creating a new snippet or choosing **Edit** on an existing one.
2. Type a name in the **Tags** field.
3. Press Enter or type a comma to turn it into a tag. Repeat for more tags.
4. Select **Save snippet** or **Save changes**.

A tag name can be up to 50 characters. Adding a name twice to the same snippet has no effect, and a name that already exists is reused instead of duplicated.

## Remove a tag

Minimum role: editor.

1. Choose **Edit** on the snippet.
2. Select the **×** on the tag.
3. Select **Save changes**.

## Filter by tag

Minimum role: viewer.

The **Tags** list in the sidebar shows every tag used by snippets in the current workspace, with a count. Select a tag to list only its snippets, and use the back arrow to clear the filter. The [search](/search) view can combine several tags: a snippet must carry all selected tags to match.

<Note>
Tag names are shared across the whole installation, but the sidebar and filters only show tags on snippets in the workspace you are viewing.
</Note>
