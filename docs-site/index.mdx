SnippetVault lets people keep and share code snippets in workspaces. Every snippet lives in a workspace, and what you can do there depends on your role.

## Workspaces, roles and projects

- A **workspace** is a shared space for members and their snippets. You always work inside one selected workspace, and you can switch between the workspaces you belong to.
- A **member** holds exactly one **role** in a workspace: owner, editor or viewer. Each workspace has exactly one owner.
- A **project** is an optional grouping of related snippets within a workspace. A snippet belongs to at most one project.

| Role | What it can do |
| --- | --- |
| Owner | Everything an editor can do, plus rename and delete the workspace, edit and delete projects, manage members and send invitations |
| Editor | Create, edit and delete snippets, create projects, assign snippets to projects, manage tags and versions |
| Viewer | Read snippets in the workspace |

See [Members and roles](/members-and-roles) for the full list.

## What you can do

- Save snippets in eight languages: [Snippets](/snippets)
