# Host public documentation on Mintlify

SnippetVault's public documentation will use Mintlify at `docs.snippetvault.me`. We chose it over continuing the custom React documentation pages because the desired task-oriented navigation, search, and article layout match its built-in documentation experience, while its free Starter plan supports Git-synced content and a custom domain. The application and documentation will have separate publishing workflows; existing `snippetvault.me/docs` links will redirect to the new site, and the docs will continue to link users back to SnippetVault.
